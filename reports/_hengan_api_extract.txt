鉴权认证


在使用开放服务接口前，需要从平台上获取服务能力的 appKey 和 appSecret，其中 appKey 是应用标
识，appSecret 是应用密钥，用以生成认证签名 sign，并作为应用鉴权的访问凭证。

   1. 获取 appKey 和 appSecret：
2. 生成 sign：

 基于 HmacSHA256 算法，将当前时间戳作为盐值，对 appKey 和 appSecret 进行哈希计算，进而生
 成认证签名 sign。

 示例（JAVA）：


    public static String getSign(String key, String secret) {
        long timestamp = System.currentTimeMillis();
        String data = String.format("%d\n%s\n%s", timestamp, secret, key);
        Mac hmacSHA256 = Mac.getInstance("HmacSHA256");
        SecretKeySpec secretKeySpec = new
    SecretKeySpec(secret.getBytes(StandardCharsets.UTF_8), "HmacSHA256");
        hmacSHA256.init(secretKeySpec);
        byte[] sign = hmacSHA256.doFinal(data.getBytes(StandardCharsets.UTF_8));
        return String.format("%d%s", timestamp, new String(new
    org.apache.commons.codec.binary.Base64().encode(sign), StandardCharsets.UTF_8));
    }


 示例 （Python）:


    import hmac
    import hashlib
    import base64
    import time

    def get_sign(key, secret):
        timestamp = int(time.time() * 1000)
        data = f"{timestamp}\n{secret}\n{key}"
        hmac_sha256 = hmac.new(secret.encode('utf-8'), data.encode('utf-8'), hashlib.sha256)
        sign = hmac_sha256.digest()
        return f"{timestamp}{base64.b64encode(sign).decode('utf-8')}"


3. 访问凭证：

 此时，appKey 和 sign 即为访问凭证。

 注意，为了保护应用安全，请勿在接口调用时携带 appSecret，同时也应尽量避免将 appKey、
  appSecret 以及生成的 sign 与他人共享或硬编码到程序。

状态码说明


请求响应的code含义见下文"状态码表格"。

FLAG状态码：服务调用反馈标识

后续接口返回的flag状态码含义：

1、标识为"0"：表示本次调用成功，无需其他操作

2、标识为"1"：表示本次调用请求处理失败 ，无需其他操作，可以直接跳过

3、标识为"2"：标识调用的服务异常，请停止调用，等待xx分钟后重试

示例：其中的flag等于2就表示当前调用出错，并且不能直接跳过

执行智能体。


基本信息


请求地址：/open/api/v2/agent/execute

请求方法：POST

Content-Type：application/json

Accept：application/json、text/event-stream

Body参数


         必
 参数         类型         说明
         须

  sid      是     string         唯一会话标志（格式需为UUID格式的字符串）

  id       是     string          智能体ID

  input     否     string        用户输入， input和inputs优先使用input

                       用户输入，参考 <附录-智能体：清单文件结构
                                    AgentManifest>中input_parameters。对于文件类型的参
  inputs     否    map<string,object>
                        数，调用接口4进行上传得到文件id，以字符串形式传给对
                       应参数

  stream     否    boolean       是否流式，默认非流式

  order     否     string             处理模式，常规routine/优先priority，默认routine

  debugSwitch  否    boolean         是否开启调试模式，默认false

header参数


 参数    必须    类型     说明

  ext     否            string        扩展参数，示例child_preview:1;reason:1


 child_preview ：是否显示子智能体的预览内容


  默认值：0 （不显示）
  可选值：

         0 ：不输出子智能体预览

         1 ：输出子智能体预览内容


  适用场景：调试多智能体协作时，便于观察子任务执行过程




 reason ：是否在最终结果中包含推理过程

  默认值：0 （包含推理过程 —— 即“拼接”到主消息中）

  可选值：

         0 ：将推理过程拼接到最终消息正文

         1 ：不拼接推理过程，但会在 mode=execute_result 的消息中额外返回一个
         reasoning_content 字段，独立存放推理内容

  适用场景：

         reason=0 ：适合需要完整上下文的前端展示
         reason=1 ：适合后端处理或需要分离“结果”与“思考”的场景

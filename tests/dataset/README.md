# T40 统一测试集 v1.0.0

本目录包含 [v1.0.0.json](v1.0.0.json) 样例标签和 C 靶标的原始页面基线。全部数据为合成内容；域名 `.invalid` 不可解析，手机号和令牌均为固定测试标记，不代表真实个人或密钥。

## 启动和验证

在仓库根目录执行：

```powershell
python tests/fixtures/verify_dataset.py
python tests/fixtures/site_server.py
```

服务器仅监听 `127.0.0.1`，按 Ctrl+C 停止。五个独立端口分别为 A `18081`、B `18082`、C `18083`、D `18084`、E `18085`。将需要测试的端口逐个登记为授权资产；请勿将服务绑定到公网地址。验证脚本使用临时端口，检查标签、页面、基线和关键标记，不依赖 Docker 或外网。

| 靶标 | 用途 | 核心证据 |
| --- | --- | --- |
| A | 漏洞与弱配置 | `/search?q=...` 原样反射 HTML；`/listing/` 暴露目录列表。仅供本机测试，勿作为公共服务部署。 |
| B | 可疑外链 | 首页含 `.invalid` 收集地址；`/about.html` 为负例。链接不会自动请求外网。 |
| C | 篡改 | 首页与 `baselines/c-index.html` 不同；`/baseline.html` 与基线相同。 |
| D | 敏感信息 | 首页含合成联系方式与令牌，`/.env`、`/backup.bak` 为合成文件。 |
| E | 正常站点 | 普通内容及安全响应头，用作误报基准。 |

`cases` 中 `positive` 是**该 URL 对指定 category 的预期标签**，不是整站安全性结论。评估时按 `id` 对齐检测结果，同一风险重复报告只算一次。C 类必须用基线文件与当前页做比较；E 类没有篡改基线，仅用于正常内容与误报检查。记录测试集版本、扫描配置、实际命中和误报口径后，再计算召回率、准确率、误报率。

该测试集覆盖可复现的反射型 HTML 注入、弱配置和内容类风险，不声称覆盖已知 CVE 的实际利用。若要评估 Nuclei 对已知 CVE 的检出能力，可结合 `deploy/授权靶场搭建方案.md` 中的 DVWA；它与本数据集分开统计。

# T41 功能用例（执行版草案）

依据：`specs/01-需求规格/SRS-02-功能规格说明书.md`、`specs/03-测试规格/TEST-01-测试计划与用例设计.md`、`specs/02-设计规格/SDD-03-接口规格.md`。本文件覆盖 SRS-02 的 F1～F7 共 29 个功能条目；原 TEST-01 中的 8 个用例编号保持不变。T41 测功能链路是否可用，检测召回率和误报率由 T42 统计。

## 执行约定

- 先复制 `T41-执行记录模板.md` 为一次执行记录，填入代码提交、环境、数据集版本、执行人和时间；每个用例单独记录结果与证据。
- 仅使用已登记授权的本地靶场。样例 ID 与预期标签以 `tests/dataset/v1.0.0.json` 为准；若样例内容再变，记录实际提交 SHA，避免只凭版本号比较。
- 管理端尚不可用时，可按 SDD-03 的对应 API 验证服务功能；需要页面交互的 F7 用例必须在管理端可用后执行。服务若运行在容器中，记录服务实际可访问的靶场地址；容器里的 `127.0.0.1` 通常指容器自身。
- 前置条件未满足时记“阻塞”，不要填“失败”；执行后与预期不符才记“失败”。真实结果和缺陷编号写入执行记录，本文件不预填通过结论。
- 涉及定时、告警、复测的用例使用隔离测试环境和合成数据，记录计划 ID、任务 ID、Finding ID，便于追踪。

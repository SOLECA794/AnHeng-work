## 2. F1 资产配置

### F1.1 授权域名录入

- 描述：录入授权域名/站点，登记授权凭证或授权备注；
- 输入：域名、备注、授权凭证（可选）、归属部门；
- 处理：校验域名格式；校验授权信息完整性；写入授权资产表；
- 输出：资产记录（含授权状态）；
- 验收：未录入域名不可被巡检；录入成功提示明确。

### F1.2 巡检范围配置

- 描述：为站点配置巡检范围（全站 / 指定路径前缀 / 子域范围）与发现深度；
- 处理：范围规则存储并作用于页面发现与检测；
- 验收：范围外的路径/域名不参与巡检；深度限制生效。

### F1.3 巡检周期配置

- 描述：配置巡检计划（周期：每日 / 每周 / 自定义 cron）、执行时段、启停；
- 处理：调度器按计划生成巡检任务；
- 验收：按周期自动触发；启停生效；执行记录可查。

### F1.4 敏感信息定义

- 描述：本单位敏感信息定义：关键词、正则表达式、文件类型、样例（样本内容或指纹）；
- 处理：规则存储、启停、按站点绑定；检测时加载规则；
- 验收：四种类型均可配置；规则变更后下次巡检生效。

## 3. F2 页面发现

### F2.1 页面与资源发现

- 描述：对授权站点爬取页面与资源（含链接、静态资源、可访问路径），登记站点页面库；
- 处理：按范围与深度约束爬取；遵循 robots 与限速配置；页面去重；记录内容摘要与哈希；
- 输出：页面清单（URL、标题、哈希、发现时间、状态）；
- 验收：发现结果可查；超范围 URL 被过滤；重复页面被去重。

### F2.2 发现范围控制

- 描述：页面发现严格限定在授权范围（域名白名单 + 路径前缀）内；
- 处理：发现过程中对每个 URL 做归属校验；超范围即丢弃；
- 验收：发现结果中不存在未授权 URL。

### F2.3 发现去重与增量

- 描述：跨轮次发现去重；支持增量发现（仅处理新增/变更页面）；
- 处理：以 URL 规范化 + 内容哈希判断变更；
- 验收：重复巡检不产生重复页面记录；变更页面被标记。

## 4. F3 风险检测

### F3.1 常见漏洞检测

- 描述：识别站点常见漏洞与组件已知漏洞（CVE）；
- 处理：指纹识别（Wappalyzer 等）→ 组件/版本比对漏洞库（Nuclei 模板）→ 非破坏验证；
- 输出：漏洞类 Finding（含证据、影响、修复建议）；
- 验收：检测非破坏；结果关联到具体页面/组件；工具调用留痕。

### F3.2 弱配置检测

- 描述：识别常见弱配置（默认口令提示、错误信息泄露、目录列举、缺失安全响应头、TLS 弱配置等）；
- 处理：按检查项调用对应工具/自研检查；
- 验收：检查项可配置；结果分级准确。

### F3.3 恶意外链 / 挂马检测

- 描述：检测页面中的恶意外链、挂马痕迹（恶意脚本、跳转、iframe、异常外联）；
- 处理：外链提取 → 黑名单/信誉库比对 + 特征规则（自研检测器）；支持样例导入比对；
- 验收：可疑外链/挂马特征被识别并给出证据；误报可标记。

### F3.4 页面篡改检测

- 描述：检测页面被篡改（内容、关键区域、首页/敏感页面）；
- 处理：与基线内容哈希比对（基线采集 → 每次巡检对比）→ 差异分析；
- 验收：篡改页面被标记并给出差异证据；支持按页面设置基线。

### F3.5 敏感信息检测

- 描述：检测页面/可访问资源中暴露的敏感信息（按本单位定义：关键词、正则、文件类型、样例）；
- 处理：对页面文本、响应头、可访问文件/资源按规则扫描；命中即记录；
- 输出：敏感信息 Finding（含命中规则、位置、样例片段——需脱敏）；
- 验收：四类规则均可命中；样例片段脱敏展示；未授权路径不检测。

## 5. F4 结果处理

### F4.1 结果归一化

- 描述：将各工具/检测器输出统一为 Finding 标准结构（类型、级别、证据、影响、修复建议、工具来源、原始数据）；
- 处理：工具适配器层完成字段映射；
- 验收：不同工具结果统一可查、可统计。

### F4.2 结果去重与关联

- 描述：同一风险跨工具、跨轮次、跨页面归并（dedup_key），支持跨 finding 关联分析；
- 处理：基于目标 + 类型 + 证据特征生成去重键；保留首次出现与最近出现时间；
- 验收：重复巡检不产生重复 Finding；关联结果可追溯。

### F4.3 结果验证

- 描述：对疑似风险进行非破坏二次确认，区分真实风险与误报；
- 处理：复测接口/规则复核；人工确认入口；
- 验收：验证状态流转（OPEN → CONFIRMED / FALSE_POSITIVE）可操作、可查。

### F4.4 分级与建议

- 描述：按严重程度与影响面分级（CRITICAL/HIGH/MEDIUM/LOW/INFO），给出证据、影响与修复建议；
- 处理：分级规则配置 + 智能体生成影响说明与修复建议；
- 验收：每个 Finding 含证据、影响、修复建议；分级规则生效。

## 6. F5 巡检闭环

### F5.1 定时巡检

- 描述：按巡检计划自动触发巡检任务（页面发现 + 各检测项）；
- 处理：调度器生成任务 → 执行流水线 → 结果入库 → 触发后续环节；
- 验收：计划触发正确；任务状态完整（排队/执行/成功/失败）；失败可重试。

### F5.2 基线对比

- 描述：维护页面内容基线，巡检时对比，识别篡改与变更；
- 处理：基线采集（首次巡检或手工设置）→ 每次对比 → 差异记录；
- 验收：基线可重建；对比结果可查。

### F5.3 告警

- 描述：按分级阈值产生告警（新增高危 Finding、篡改命中、敏感信息命中）；
- 处理：告警规则配置 → 触发告警 → 通知（站内/可选邮件）；
- 验收：告警与 Finding 关联；告警去重（同风险不重复告警）；已读/处理状态可管理。

### F5.4 复测

- 描述：对已发现风险在修复后进行再次检测确认；
- 处理：复测入口（按站点/按 Finding）→ 重新执行对应检测 → 状态更新（FIXED / RETESTED）；
- 验收：复测结果可追溯；修复后状态可流转。

### F5.5 报告导出

- 描述：按站点/时间段生成巡检报告并导出（含资产、任务、风险分布、明细、趋势、建议）；
- 处理：报告模板 + 数据聚合 → 导出文件（HTML/PDF）；
- 验收：报告内容与数据一致；可下载；含证据与修复建议。

## 7. F6 智能体运行（恒脑平台）

### F6.1 任务规划

- 描述：智能体理解巡检请求（自然语言或计划触发），规划任务序列（发现 → 检测 → 分析 → 报告）；
- 处理：恒脑平台内任务规划，调用能力服务工具；
- 验收：复杂请求可拆解为可执行步骤；规划可解释（轨迹可见）。

### F6.2 工具选择与编排

- 描述：智能体按目标选择并编排合规工具（漏洞、配置、挂马、篡改、敏感信息）；
- 处理：工具注册与描述 → 选择 → 编排执行 → 结果汇总；
- 验收：工具选择合理；编排顺序正确；非破坏工具白名单强制校验。

### F6.3 结果关联分析

- 描述：智能体对多工具结果进行关联去重、分级、生成影响与修复建议；
- 处理：调用结果处理服务（F4）+ 模型生成解释；
- 验收：解释可读、有依据；建议可执行。

### F6.4 对话交互

- 描述：运维人员以自然语言发起巡检、查询风险、生成报告（恒脑对话 + 管理端均可）；
- 处理：意图识别 → 任务规划 → 工具调用 → 结果回复；
- 验收：典型指令（"对 xx.com 执行一次巡检"、"查看最近的高危风险"、"生成本周报告"）可完成。

## 8. F7 管理端

### F7.1 资产与规则管理

- 描述：授权资产、巡检计划、敏感信息规则、工具配置的管理界面；
- 验收：CRUD 完整；操作留痕。

### F7.2 巡检与结果可视化

- 描述：任务状态、风险分布（按类型/级别/站点）、趋势图、Finding 明细与证据查看；
- 验收：数据与明细一致；可视化清晰；空态有提示。

### F7.3 告警与复测管理

- 描述：告警列表、处理、复测入口；
- 验收：流转闭环可操作。

### F7.4 审计与系统配置

- 描述：审计日志查询（巡检、工具调用、结果操作）、用户管理、系统配置；
- 验收：日志可查可筛；权限隔离生效。

# SDD-08 · 风险分级契约（T23）

> 状态：v1.0 实现提案，随功能 PR 评审；日期：2026-10-15；责任人：D。
> 依据：SRS-02 F4.4、SDD-01 §5.6；细化现有要求，不修改既有基线和数据库结构。

## 1. 输入与接入位置

`grade_finding(record, context, policy)` 接受 T21 标准安全记录、可信 `GradingContext` 和外置策略，返回独立分级结果。先归一化及去重，再分级；`graded_orm_values` 先调用 T21 的字段转换，再覆盖 severity/impact/suggestion 并将分级依据写入 raw_data.grading，不修改输入、身份、证据、状态和检测时间。

T21 的严格历史校验只接受其原有标准记录。T23 返回的 ORM 值不能直接回传给 T21 作为标准历史；调用方保留 T21 标准快照，完成历史归并后重新分级。持久化读模型适配、事务写入和在线流水线装配后续联调，本次不扩大 T21 历史白名单。

上下文含 scope_id、target_sha256、page_importance（NORMAL/HOME/LOGIN/CORE/UNKNOWN）、exposure（INTERNET/INTERNAL/RESTRICTED/UNKNOWN），以及可选的 cvss_score、rule_id。资产及目标指纹必须与记录一致。原始 URL 已被 T21 脱敏，页面重要性由授权发现/资产元数据提供，不能从显示 URL 猜测；不得把外部请求参数当作可信资产事实。本纯函数不提供认证或扫描入口。

## 2. 基础分级

- VULN 有合法 CVSS v3.1 分数时：0→INFO；0.1–3.9→LOW；4.0–6.9→MEDIUM；7.0–8.9→HIGH；9.0–10.0→CRITICAL。只接受有限数值或普通十进制字符串，0–10 且最多一位有效小数；拒绝 bool、NaN、Infinity、越界、向量及非法值。缺失时沿用检测器等级并标记回退，不将缺失误当 0。
- 该映射依据 [FIRST CVSS v3.1 表 14](https://www.first.org/cvss/v3.1/specification-document#i5)。这是已有分数的等级转换，不计算向量，也不产生新的 CVSS 分数。
- 非漏洞类型按 `(type, tool_name, rule_id)` 精确匹配策略覆盖等级；未配置的规则沿用检测器等级并标记回退。rule_id 仅用于匹配，不原文输出。不同工具的同名规则互不覆盖。
- 指纹不是独立风险，不进入分级。畸形记录及配置明确失败，不悄悄降低等级。

## 3. 影响面调整（项目策略，非 CVSS 环境分数）

首页、登录页、核心路径及互联网暴露分别设置最低等级，取基础级别与命中最低级别中的最高者，不叠加升级，不降低原有风险。默认重要页面与互联网暴露的最低级别均为 HIGH；NORMAL/UNKNOWN 页面和内部/受限/未知暴露不调级。INFO 保持 INFO（包括 CVSS 0），避免把纯提示升为漏洞。

输出保留 base_severity、severity、base_source、固定 reason_codes、页面/暴露枚举、策略版本与 SHA256；调整后的 severity 是项目处置等级，不能标为调整后的 CVSS。未知上下文明确记录 UNKNOWN，不推断为公网或核心业务。

## 4. 证据、影响与建议

证据沿用 T21 脱敏指纹；影响及可执行建议由固定分类模板兜底，并附页面/暴露范围说明，措辞保持“可能/需核实”，不把未确认发现宣称为已利用。本次不直接执行模型、不复制工具自由文本、不自动修复目标。恒脑生成的增强说明和质量评估随 T30 后续联调，模型暂不可用不阻塞规则兜底输出。

## 5. 策略与验收

外置 JSON 文件 `src/config/risk-grading.json`：版本、重要页面最低等级、暴露范围最低等级、按工具和风险类型绑定的规则等级。配置严格验证字段、枚举、重复 JSON 键、重复规则、体积及数量限制；完整策略计算规范 JSON 的 SHA256。无新增第三方运行依赖。

验收覆盖 CVSS 边界与异常、规则覆盖与工具隔离、影响面取高/不叠加/INFO 保持、可信上下文错配、输入不可变、脱敏、策略变更追踪，以及 T20/T21/T18/T19 输出接入。采用固定本地样例与纯函数，不代表真实平台、生产数据库或在线流水线联调通过。

## 2. 测试集搭建（统一测试集）

检测效果评估必须基于**可复现的测试集**，含靶场与样例集两部分：

### 2.1 靶场（自建演示/测试站点）

| 靶标 | 覆盖类型 | 构造内容 |
| --- | --- | --- |
| 漏洞靶标 A | 常见漏洞（组件已知漏洞、弱配置） | 部署含已知版本组件（如旧版框架）、弱配置（目录列举、默认页、缺安全头）的站点 |
| 挂马靶标 B | 恶意外链 / 挂马 | 页面植入恶意脚本特征、可疑外链、iframe 挂载样例 |
| 篡改靶标 C | 页面篡改 | 相对基线的页面内容变更（首页、敏感页） |
| 泄露靶标 D | 敏感信息 | 页面/文件暴露关键词、正则（手机号/邮箱/身份证）、敏感文件类型（.env/.git/.bak） |
| 正常站点 E | 误报基准 | 干净合规站点，用于统计误报率 |

### 2.2 样例集

- 每个类型提供固定数量的正例（真实风险）与负例（正常内容）；
- 样例集版本管理（`tests/dataset/`），评估结果与样例集版本对应；
- 样例集构造遵循非破坏原则，全部为自建演示资产。

### 2.3 评估指标定义

- T42 以样例集中的 `case.id + category` 为一个判定单位，`positive` 是该单位的真值；同一单位出现多条同类别 Finding 只计一次。非本类别的 Finding 不用于该单位判定。
- 已执行的正例：命中为 TP，未命中为 FN；已执行的负例：命中为 FP，未命中为 TN。阻塞或未执行不进入四格表，也不能当作 FN/TN；未覆盖全部样例时仅报告部分观察值，不给出最终达标结论。
- 召回率 = TP / (TP + FN)；准确率（Precision）= TP / (TP + FP)。主误报率采用**负例命中比例** FPR = FP / (FP + TN)；另报**告警中误报占比** FDR = FP / (TP + FP)，避免两种口径混用。分母为 0 时记 N/A，不记 0%。
- 分别按 `VULN + WEAK_CONFIG`、`MALICIOUS_LINK + MALICIOUS_SCRIPT`、`TAMPER`、`SENSITIVE` 汇总四类，另列每个原始 category 和正常站点 E 的负例结果。E 当前没有 `MALICIOUS_SCRIPT`、`TAMPER` 标签，不能以 E 的零误报证明这两类无误报。
- 每轮报告记录样例集版本和文件哈希、代码提交、扫描配置、任务与 Finding 证据；同类别的“0 命中”须有已知正例作观测对照。具体输入格式与复算方式见 `tests/effectiveness/T42-评估口径与执行说明.md`。

## 3. 用例设计大纲

### T1 功能用例（节选，对应 SRS-02 F 编号）

| 用例 | 关联功能 | 步骤要点 | 预期 |
| --- | --- | --- | --- |
| TC-F1-01 授权域名录入 | F1.1 | 录入合法/非法域名、无授权信息 | 合法可入；未授权域名不可被巡检 |
| TC-F1-04 敏感规则定义 | F1.4 | 四类规则各配一条并启停 | 规则生效；停用后不再命中 |
| TC-F2-01 页面发现 | F2.1 | 对授权站点触发发现 | 页面入库；超范围 URL 被过滤 |
| TC-F3-05 敏感信息检测 | F3.5 | 在泄露靶标执行 | 命中并脱敏展示证据 |
| TC-F4-02 去重 | F4.2 | 同风险连续两次巡检 | 不产生重复 Finding；last_seen 更新 |
| TC-F5-03 告警 | F5.3 | 构造高危 Finding | 告警生成且不重复 |
| TC-F5-05 报告导出 | F5.5 | 生成并下载报告 | 内容与数据一致 |
| TC-F6-01 任务规划 | F6.1 | 自然语言请求巡检 | 规划步骤正确、轨迹可见 |

## 4. 测试执行与产出

- 执行记录：按用例记录结果（通过/失败/阻塞），失败关联缺陷编号；
- 测试报告：`reports/测试报告.md`（或导出），包含测试集版本、指标口径、分项结果、缺陷清单；
- 回归：核心闭环（发现→检测→结果→报告）每次版本迭代后回归。

# 网站安全智能巡检智能体（Learning-Agent 工程）

> 工程目录沿用 `learning-agent`（智能体工程代号）。

## 课题信息

| 项 | 内容 |
| --- | --- |
| 赛题 | 企业赛题：面向网站安全风险评估与敏感信息防泄露的智能巡检智能体 |
| 命题企业 | 杭州安恒信息技术股份有限公司 |
| 交付形态 | 可在恒脑安全智能体平台运行的智能体原型 + 管理端 + 开源工具编排层 + 完整工程文档 |
| 核心目标 | 授权前提下，周期性发现站点及下属页面，编排合规开源安全工具完成风险评估、内容完整性检测与敏感信息检查，形成可解释、可跟踪、可复测的风险闭环 |

## 项目文件系统（SDD 治理范式）

```
learning-agent/
├── specs/                    # 规格库（SDD：Spec-Driven Development，以规格为源头）
│   ├── 01-需求规格/          # SRS：需求规格
│   ├── 02-设计规格/          # SDD：架构 / 数据 / 接口规格
│   └── 03-测试规格/          # TEST：测试计划与用例设计
├── docs/                     # 治理与过程文档
│   ├── 01-项目治理/          # 开发计划、协作规范
│   ├── 02-质量与验收/        # 验收标准（对齐赛题评价指标）、交付清单
│   └── 99-归档/              # 历史方案归档
├── src/                      # 源码（智能体 / 工具编排 / 业务服务 / 管理端）
├── scripts/                  # 脚本（调度、初始化、数据工具）
├── tests/                    # 测试
├── deploy/                   # 部署（Docker Compose、环境配置）
└── reports/                  # 交付报告（测试报告、巡检报告样例）
```

## 建议阅读顺序

1. `specs/01-需求规格/SRS-01-项目概述与需求基线.md` —— 课题背景、目标、边界；
2. `specs/01-需求规格/SRS-02-功能规格说明书.md` —— 按赛题答题要求拆解的功能规格；
3. `specs/02-设计规格/SDD-01-系统架构与关键技术设计.md` —— 总体架构与关键设计；
4. `specs/02-设计规格/SDD-02-数据模型设计.md`、`SDD-03-接口规格.md` —— 数据与接口；
5. `docs/01-项目治理/01-开发计划与里程碑.md` —— 开发顺序与阶段验收；
6. `docs/02-质量与验收/01-验收标准-对齐赛题评价指标.md` —— 对照赛题评分细则。

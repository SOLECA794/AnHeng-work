# 01 · 验收标准（对齐赛题评价指标）

> 本文件把赛题五项评价指标逐项拆解为可验收的细则，作为项目验收与自评依据。

## 1. 功能完整性（25%）

| 评分点（赛题） | 验收细则 | 对应规格 |
| --- | --- | --- |
| 资产与页面发现 | 授权域名录入、巡检范围配置、页面/资源发现、范围过滤、去重 | SRS-02 F1.1–F1.2、F2 |
| 周期巡检 | 巡检计划配置、定时触发、任务状态可查、失败重试 | SRS-02 F1.3、F5.1 |
| 风险检测 | 漏洞、弱配置、恶意外链/挂马、篡改、敏感信息五类均可检测 | SRS-02 F3 |
| 敏感信息自定义 | 关键词、正则、文件类型、样例四类规则可配置并生效 | SRS-02 F1.4 |
| 告警及报告闭环 | 告警生成与去重、报告生成与导出、复测闭环 | SRS-02 F5.3–F5.5 |

## 2. 检测效果（30%）

- 在统一测试集（靶场 + 样例集）上对漏洞/挂马/篡改/泄露四类分别评估；
- 记录召回率、准确率、误报率（口径见 TEST-01 §2.3）；
- 验收要求：评估过程可复现（测试集版本化），结果写入测试报告；
- 目标基线（建议值，演示阶段依据实测校准）：四类召回率与准确率达到可展示水平，误报率可控；具体数值以测试报告为准。

## 3. 智能体能力（20%）

| 评分点（赛题） | 验收细则 |
| --- | --- |
| 任务规划 | 自然语言请求可拆解为可执行步骤，规划轨迹可见 |
| 工具选择与编排 | 按检测目标选择合适工具/检测器，编排顺序合理，非破坏约束生效 |
| 结果关联去重 | 跨工具/跨轮次同风险归并，不重复展示 |
| 证据解释和修复建议 | 每个 Finding 含可理解证据、影响说明与可执行修复建议（人工评分） |

## 4. 安全合规（10%）

| 评分点（赛题） | 验收细则 |
| --- | --- |
| 授权边界 | 未授权域名/URL 一律拒绝并留痕（40310） |
| 限速 | 请求频率受限，目标负载受控 |
| 最小权限 | 服务账号与工具容器最小权限；敏感数据脱敏 |
| 日志审计 | 巡检、工具调用、结果操作全量留痕可查 |
| 非破坏性 | 检测不改变目标内容与状态；利用类动作禁止 |

## 5. 工程化与创新（15%）

| 评分点（赛题） | 验收细则 |
| --- | --- |
| 部署易用性 | Docker Compose 一键启动；配置外置 |
| 稳定性 | 工具超时/异常降级；任务可重试；结果幂等 |
| 扩展性 | 新增工具仅加适配器，不改核心 |
| 可视化 | 管理端资产、任务、风险分布、趋势可视化与数据一致 |
| 创新价值 | 智能体任务规划与关联分析的智能化程度（如跨工具归并、自动建议生成） |

## 6. 交付要求（答题要求⑤⑥）

- 系统架构、工具清单、演示环境、源代码/部署说明、测试报告齐备（见 `02-交付清单.md`）；
- 智能体可在恒脑安全智能体平台中运行（编排适配层验证通过）。

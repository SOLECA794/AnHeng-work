## 演示前准备

在仓库根目录使用 PowerShell：


创建账号时通过隐藏输入设置密码。默认开发 admin 只用于管理，不能代替运维账号。`.env` 中设置自己的 JWT 密钥与开发管理员密码；真实平台凭据只写服务端配置，演示时不要展示配置文件、Authorization 头或完整 Token。

浏览器打开 `http://127.0.0.1:8000/docs`。当前后端已挂载 health、auth、agent/logs。C/D 的能力服务、完整业务路由及前端页面按主干集成进度另行验收；不能将独立模块单测当作完整产品演示。

## 答辩讲稿要点

- **架构职责**：恒脑负责规划与工具选择，能力服务负责身份、授权、工具白名单、持久化与风险闭环，管理端负责展示和人工确认。
- **工程贡献**：B 已提供服务骨架、ORM/工具契约、JWT 与持久化用户、可替换 AgentProvider、平台协议解析及脱敏审计；本轮重点修复协议与工程安装缺陷。
- **错误恢复**：并发拒绝有界退避，日配额不重复请求；已有流输出或不确定已提交时不自动重放，避免重复操作。
- **可解释性**：记录工具动作、结果状态和耗时；风险结果引用规则、证据与建议；对话生成的文本不自动修改已验证状态。
- **验收口径**：分清单元测试、SQLite 集成、平台实测和完整业务演示。数据库/平台尚未联调的项目如实列出，不虚报完成率。

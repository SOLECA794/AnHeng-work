# 治理与过程文档

本目录存放**治理与过程类文档**（计划、规范、验收、交付、归档），与 `specs/` 规格库区分：规格库回答"做什么、怎么做、怎么测"，本目录回答"怎么组织、怎么协作、怎么验收、交什么"。

## 目录约定

| 目录 | 内容 |
| --- | --- |
| `01-项目治理/` | 开发计划与里程碑、开发协作与规范 |
| `02-质量与验收/` | 验收标准（对齐赛题评价指标）、交付清单 |
| `99-归档/` | 历史方案归档（不参与当前开发，仅留存） |

## 文档生命周期

1. 新文档先在本目录创建草案，评审通过后生效；
2. 治理类文档变更走版本号 + 变更记录，不静默改写；
3. 归档目录只增不删；归档文件命名保留原编号并加前缀说明。

## 与规格库的关系

- 开发计划引用规格文件编号（如"阶段 B 对应 SRS-02 F2/F3"）；
- 验收标准逐项映射赛题评价指标（功能完整性 / 检测效果 / 智能体能力 / 安全合规 / 工程化与创新）；
- 交付清单对照答题要求⑤⑥（架构、工具清单、演示环境、源码/部署说明、测试报告、恒脑运行）。

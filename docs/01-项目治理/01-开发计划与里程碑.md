# 01 · 开发计划与里程碑

> 按治理要求：本文档**不含时间排期与人员分工**，只给出开发顺序、模块划分、阶段验收标准与交付准备。

## 1. 开发顺序总览

依赖关系决定顺序，原则：先地基后业务、先闭环后扩展、先能力后界面。

```
阶段 A（地基）：工程骨架、认证鉴权、统一响应、恒脑适配层接入、工具适配框架
阶段 B（资产与调度）：授权资产、巡检计划、调度器、页面发现
阶段 C（检测能力）：漏洞/弱配置、外链挂马、篡改对比、敏感信息检测（工具编排 + 自研检测器）
阶段 D（结果闭环）：归一化、去重、验证、分级、告警、复测、报告
阶段 E（智能体编排）：任务规划、工具选择、关联分析、对话交互（恒脑）
阶段 F（管理端）：资产/规则管理、巡检可视化、告警复测、报告导出、审计
阶段 G（收尾）：测试集与检测效果评估、合规测试、部署、演示与交付文档
```

能力服务先出接口，管理端可并行开发并以 Mock 先行；智能体对话在 D 阶段闭环后可测。

| 模块 | 关联规格 | 关键实现点 |

## 3. 里程碑与验收标准（按阶段）

| 阶段 | 里程碑成果 | 验收标准 |
| --- | --- | --- |
| A 地基 | 服务可启动、认证可用、恒脑连通、工具框架可用 | 鉴权/统一响应通过；恒脑 OpenAPI 连通性验证；工具注册与非破坏校验生效 |
| B 资产与调度 | 资产录入、计划调度、页面发现闭环 | 未授权被拒（40310）；计划按周期触发；页面发现去重正确 |
| C 检测能力 | 四类检测在测试集上可执行 | 靶标 A–D 均有检出；执行非破坏；超时降级正常 |
| D 结果闭环 | 归一化→去重→验证→分级→告警→报告闭环 | dedup 生效；状态流转正确；报告与数据一致 |
| E 智能体编排 | 自然语言发起巡检/查询/报告 | 典型指令全流程跑通；规划轨迹可见；关联分析合理 |
| F 管理端 | 配置、可视化、告警复测、报告导出、审计可用 | CRUD 完整；图表与数据一致；权限隔离生效 |
| G 收尾 | 测试集评估、合规测试、部署、演示、交付文档 | 检测效果指标记录完整；合规用例通过；一键部署成功；交付清单齐备 |

## 4. 联调与演示准备

- 联调环境：能力服务共享部署 + 统一数据库；管理端连接联调环境；
- 演示准备：
  - 演示账号（admin / 运维账号）；
  - 演示资产（测试域名，接入统一测试集靶场）；
  - 演示流程：登录 → 录入授权资产 → 配置巡检计划 → 手动巡检 → 查看风险与证据 → 告警/复测 → 生成报告 → 智能体对话演示；
  - 演示材料：系统架构说明、工具清单、演示环境说明、测试报告、部署说明、演示视频。

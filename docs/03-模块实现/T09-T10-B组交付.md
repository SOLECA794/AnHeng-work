# T09/T10 · B 组实现与验收边界

版本：v1.0，2026-10-19。依据：SDD-02、SDD-03 §4.1、SDD-07、恒脑实测样例。

## 实现约定

- 认证使用 `sys_user`：角色只接受 ADMIN / SEC_OPS / RULE_ADMIN；停用、删除、修改密码立即使旧凭证失效。密码使用加盐 scrypt。
- `POST /api/auth/password` 接收 `oldPassword`、`newPassword`，成功后所有旧 Token 失效，重新登录。登录返回 `token`、`tokenType`、`expiresIn`、`user`；用户信息含 `id`、`username`、`nickname`、`role`。
- 退出在现有 `agent_log` 表记录 `log_type=AUTH`、`action=logout` 和 JWT 标识的 SHA-256；不存 Token 本身。跨进程/重启查询该记录拒绝旧 Token。密码更新使用旧哈希比较更新，避免并发覆盖。
- 开发环境默认使用 `.local/anheng.db`（SQLite），仅开发模式生成兼容 DDL。生产配置 PostgreSQL `DATABASE_URL` 并先应用已有 `db/schema.sql`；不自动迁移生产数据库。生产不创建默认账号，要求显式 JWT 密钥。
- 恒脑所有 JSON 返回接受 `code=0` / `"0"`，错误输出固定说明，不回传上游原始错误/URL/凭据。异步 submit、upload 的 `data` 允许直接字符串；download 使用 POST JSON；resume 返回完成时间，原 execute 流继续输出。
- 错误码以 SDD-03 为准：签名/接口权限为 40300，输入错误为 40001，日配额/并发为 50002，服务/协议异常为 50001。-304 不自动重试；-300/-301 在未消费任何流数据前有界退避。不会在不确定提交成功时重复 execute/submit。
- 默认每实例执行请求并发最多 2，单 sid 执行串行；流占用配额直到关闭，resume/stop 使用独立的有界控制槽位。多进程及运行中的异步任务总量需由调用方/网关统一调度。调用轨迹使用 `agent_log`，只记录动作、状态、耗时和错误码，不保存输入、完整回复或文件内容。

依赖修复：清除 `requirements.txt` 中残留冲突标记，保留双方依赖；补 PostgreSQL 驱动及 python-Wappalyzer 所需 `pkg_resources` 兼容范围。安装说明包含 Windows UTF-8 模式。

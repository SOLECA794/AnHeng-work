# src/ 源码规划

按 SDD 治理，源码模块与设计规格一一对应。当前为**骨架规划**，模块职责与关键技术点如下；实现按 `specs/02-设计规格/SDD-01-系统架构与关键技术设计.md` 展开。

| 目录 | 模块 | 职责 | 关键技术点 |
| --- | --- | --- | --- |
| `agent/` | 智能体核心 | 恒脑编排适配（AgentProvider 统一接口）、任务规划、工具调用循环、审计埋点 | 恒脑 OpenAPI（execute/异步任务/交互回答）、状态码映射、凭据安全（仅服务端持密） |
| `tools/` | 工具编排层 | 开源安全工具统一适配器；自研检测器（篡改/外链挂马/敏感信息） | 工具注册表（白名单）、ToolAdapter、限速/超时、非破坏校验 |
| `services/` | 业务服务 | 资产、页面发现、调度、检测任务、风险结果、告警、报告、基线 | 爬虫与页面发现、调度器、去重/分级/复测、权限与审计 |
| `web/` | 管理端 | 配置（授权域名/周期/敏感词）、巡检可视化、告警、报告导出、审计 | React 18 + TypeScript + Vite + Ant Design + ECharts |

## 开发约定

- 语言：能力侧 Python 3.11 + FastAPI；管理端 React 18 + TypeScript（见 SDD-01 技术栈）；
- 分层：路由 → 服务 → 数据，禁止跨层直连；工具适配器统一实现 `ToolAdapter` 接口；
- 新增工具必须登记工具注册表并实现非破坏校验（见 SDD-01 §5.3/§5.8 与 `docs/02-质量与验收/03-工具清单与合规声明.md`）；
- 所有对外接口遵循 `specs/02-设计规格/SDD-03-接口规格.md`；
- 全局原则（SDD-01 §5.10）：通用性、可扩展性、可替换性（脱离平台绑定）、可维护性、工程化。

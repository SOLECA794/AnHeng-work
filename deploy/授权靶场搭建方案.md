# 授权测试靶场搭建方案（本地 DVWA）

> 状态：基线 v1.0（2026-10-11）
> 用途：为巡检智能体提供**授权测试目标**（T15–T20 真实检测链路验收前提）；仅本机/局域网内使用，明确授权，禁止对外暴露
> 前置：本机已安装 Docker Desktop（未安装见 §4 备选方案）

## 1. 靶场选择

**DVWA（Damn Vulnerable Web Application）**——经典 Web 漏洞靶场，覆盖 SQL 注入/XSS/文件上传/弱口令/信息泄露等，与 Nuclei 模板检测项对齐，适合验证"页面发现 → 漏洞检测 → 分级报告"全链路。

## 2. 部署步骤（Windows PowerShell）

```powershell
# 1) 确认 Docker 已安装
docker --version

# 2) 拉取并启动 DVWA（映射本机 8080 端口）
docker run -d --name dvwa -p 8080:80 vulnerables/web-dvwa

# 3) 确认启动（等待 10-20 秒初始化数据库）
docker ps

# 4) 访问靶场
#    浏览器打开 http://localhost:8080
#    默认账号 admin / 密码 password（登录后先点 "Create / Reset Database"）
```

## 3. 授权登记（重要）

部署完成后，把靶场登记为**本项目授权测试目标**：

| 项 | 值 |
| --- | --- |
| 授权目标 | `http://localhost:8080`（若需局域网访问：本机 IP + 8080，如 `http://192.168.x.x:8080`） |
| 授权范围 | 仅该靶场，禁扫公网/未授权资产 |
| 检测模式 | 非破坏：Nuclei 模板化 + SSL 检测 + 页面发现，禁止 SQLmap 注入利用 |
| 登记位置 | 本项目工具清单与合规声明（授权资产清单） |

> 巡检输入示例：`target_url=http://localhost:8080`，`scope=全站`，`check_types=ssl/vuln`。

## 4. 备选方案（无 Docker）

- Windows 装 PHPStudy（集成 Apache+PHP+MySQL），下载 DVWA 源码放入站点目录，按安装说明配置数据库；
- 或使用 OWASP Juice Shop（Node.js）作为补充靶场（侧重业务逻辑漏洞）。

## 5. 靶场能力与赛题对应

| 赛题检测项 | DVWA 对应 |
| --- | --- |
| 漏洞检测（SQLi/XSS/上传） | DVWA 核心模块 |
| 弱配置/信息泄露 | 默认配置、错误信息、文件包含 |
| 敏感信息检测 | 可放置含手机号/密钥的测试文件于靶场站点目录 |
| 挂马/篡改检测 | 可模拟插入恶意 iframe 的测试页（Phase 2） |
| 页面发现 | DVWA 站点结构（登录/模块页） |

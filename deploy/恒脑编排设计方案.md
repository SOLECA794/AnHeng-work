# 恒脑编排设计方案（网站安全智能巡检 Agent，T27）

> 状态：基线 v1.0（2026-10-11）
> 依据：恒脑平台编排能力（`deploy/恒脑平台文档/07-平台编排操作要点.md`）+ 平台能力清单（`deploy/恒脑平台实测与能力清单.md`）
> 执行方式：路径 B——纯平台可视化操作（/development），无需开放接口凭据
> 配套：发布后生成智能体 ID 供后续开放接口调用

## 1. 编排目标

在恒脑平台上构建"网站安全智能巡检 Agent"：用户输入授权域名后，智能体自主完成
**页面发现 → 安全检测（漏洞/SSL/敏感信息） → 结果汇总**，输出可解释的风险项（证据、影响、修复建议），全程非破坏、授权确认、可跟踪。

- 智能体名称建议：`网站安全巡检Agent`
- 输入参数：`target_url`（授权域名，必填）、`scope`（范围：首页/全站，默认全站）、`check_types`（检测类型数组，可选：ssl/vuln/sensitive/tamper，默认全部）
- 输出：风险项列表（risk items）+ 摘要

## 2. 工作流节点拓扑（Phase 1：纯平台能力版）

```
[开始节点] → [交互节点·授权确认] → [自规划节点] → [代码节点·结果聚合] → [结束节点]
```

| 节点 | 作用 | 关键配置 |
| --- | --- | --- |
| 开始节点 | 声明输入参数 | input: target_url(String, 必填), scope(String, 选填), check_types(Array, 选填)；模型配置留默认 |
| 交互节点 | 授权确认（非破坏合规） | 问题类型"填空"：`请确认目标域名已获授权，输入确认口令或"确认"继续`；问题名 `auth_confirm` |
| 自规划节点 | **核心**：自主规划并编排 MCP/技能 | 模型选**最大上下文 ≥128K** 的可用模型；勾选白名单内 MCP（见 §4）；系统提示词见 §3.1 |
| 代码节点 | 结果归一化/去重/分级（轻量） | Python；输入取自规划节点输出；输出 findings 数组（见 §3.3） |
| 结束节点 | 输出最终结果 | 回答内容=汇总摘要；输出参数 findings(Array) |

> 说明：Phase 1 不依赖能力服务（自研检测器），用平台 MCP + 知识库 + 代码节点先跑通闭环；篡改/挂马检测等能力服务接口注册后，在自规划节点后追加"插件节点"（见 §5 Phase 2）。

## 3. 关键节点配置模板

### 3.1 自规划节点系统提示词（直接复制使用）

```
你是网站安全智能巡检 Agent。你只对被明确授权且经人工确认的域名执行安全巡检，全程非破坏：
只做只读检测与模板化扫描，禁止利用、注入、爆破、绕过认证，禁止向未授权目标发起请求。

巡检流程（按顺序自主规划执行）：
1. 页面发现：调用子域名发现 / 证书透明查询 MCP，结合 target_url 与 scope 确定巡检目标清单；
2. 传输安全：调用 SSL/TLS 检测 MCP，检查证书有效性、协议版本与弱配置；
3. 漏洞检测：调用 Nuclei 漏洞扫描 MCP（模板化、非利用），识别常见漏洞与弱配置；
4. 敏感信息：基于安全巡检知识库（RAG）比对，检查页面/资源中可能暴露的敏感信息模式；
5. 结果汇总：对发现项给出 风险等级、证据、影响说明、修复建议。

输入参数：target_url（授权域名）、scope（首页/全站）、check_types（ssl/vuln/sensitive 等）。
输出要求：每个风险项必须包含 evidence（证据摘要，敏感信息需脱敏）、impact、recommendation、
severity（high/medium/low）。无法确认授权的目标一律先请求人工确认，不得直接扫描。
```

### 3.2 交互节点配置

| 配置项 | 值 |
| --- | --- |
| 问题名称 | `auth_confirm`（英文数字下划线，数字不能开头） |
| 问题类型 | 填空 |
| 问题内容 | `开始巡检前请确认：目标 {target_url} 已获得合法授权。输入"已授权"继续。` |
| 输出参数 | auth_confirm_question / auth_confirm_answer |

### 3.3 代码节点（结果聚合，Python 示例骨架）

```python
# 输入: results = 自规划节点输出（原始结果，含各 MCP 返回）
# 输出: findings
import json
findings = []
for item in results:
    sev = "high" if "critical" in str(item).lower() else "medium"
    findings.append({
        "title": item.get("name", "未命名风险"),
        "severity": sev,
        "evidence": item.get("evidence", "见原始输出")[:200],
        "impact": "详见报告",
        "recommendation": item.get("recommendation", "参照安全巡检知识库建议"),
    })
```

## 4. MCP / 技能勾选（白名单内，对齐三档评估）

| 类型 | 勾选 | 说明 |
| --- | --- | --- |
| ✅ 勾选 | 子域名发现、证书透明查询、SSL/TLS 检测、Nuclei 漏洞扫描、DuckDuckGo 搜索、时间感知服务 | 只读/模板化，符合非破坏 |
| ⚠️ 不勾（评审后） | Nmap、Masscan、Amass、Web 模糊测试、HTTP 参数发现、WordPress 安全检测 | 主动探测，默认不启用 |
| ❌ 不勾（禁止） | SQLmap、渗透测试工具集、SSH 远程命令、MySQL 安全交互、Webhook/钉钉/企微 | 破坏性/远程执行，赛题禁止 |

技能（可选）：勾选"检测工程师"或"高级安全运营"增强规划质量（技能作为编排参考，不直接执行检测）。

## 5. 知识库配置（T06 落地）

平台当前 0 个知识库，需创建 2 个（单库 ≤20 文件、≤100M，分块默认 512）：

| 知识库 | 类型 | 内容 | 用途 |
| --- | --- | --- | --- |
| `安全巡检知识库` | 文本库 | 常见漏洞与弱配置说明、修复建议（可先传 OWASP/等保公开资料节选） | 智能体生成证据解释与修复建议 |
| `敏感信息定义库` | 文本库 | 敏感信息关键词、正则、样例说明文档（手机号/身份证/密钥/内网地址等定义） | 敏感信息泄露识别依据（Phase 2 与能力服务检测器协同） |

## 6. 发布与验证

### 6.1 发布
编排调试通过后发布 → 生成唯一智能体 ID（"我的创建"中未发布智能体不可被调用，务必发布）。

### 6.2 验证用例（平台上直接对话测试）

| 用例 | 输入 | 预期 |
| --- | --- | --- |
| 授权确认 | `对 example.com 做安全巡检` | 触发交互节点问题，未确认不扫描 |
| 确认后巡检 | `已授权` | 自规划节点依次调用发现/SSL/Nuclei，输出风险项清单（含 evidence/impact/recommendation/severity） |
| 范围约束 | `只检测 example.com 首页 SSL` | 仅执行 SSL/TLS 检测，不扩散 |
| 非破坏校验 | 任意输入 | 不出现 SQLmap/SSH 等破坏性工具调用 |

### 6.3 验收对照（赛题 5 项评分）
- 功能完整性（25%）：资产发现/检测/敏感信息/输出闭环在编排中可见；
- 检测效果（30%）：Nuclei 模板 + SSL + 知识库比对产出真实风险项（真实目标待授权）；
- 智能体能力（20%）：自规划节点自主拆解流程、按需调用 MCP、结果带证据与建议；
- 安全合规（10%）：交互授权确认 + 白名单 MCP + 非破坏提示词；
- 工程化与创新（15%）：可 JSON 导入、发布后开放接口可调用、可与能力服务协同扩展。

## 7. Phase 2 扩展（能力服务就绪后）

能力服务开发完成后，编排追加：
1. **API 工具注册**：将能力服务接口（篡改检测、敏感信息检测、报告生成）注册为 API 工具能力项（调试通过后才能在编排选中）；
2. 自规划节点后追加**插件节点**：调用"篡改检测能力项""敏感信息检测能力项"；
3. 结束节点引用报告生成能力项输出；
4. 形成完整"发现→检测→聚合→报告"闭环。

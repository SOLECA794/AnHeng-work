# deploy/ 部署目录

部署架构见 `specs/02-设计规格/SDD-01-系统架构与关键技术设计.md` §6。

规划内容：

```
deploy/
├── docker-compose.yml    # 能力服务 + 数据库 + 管理端 + 工具环境
├── .env.example          # 环境变量模板（数据库、JWT、恒脑 API、限速参数）
├── README.md             # 部署说明（一键启动、配置、运维）
└── 恒脑接入说明.md        # 恒脑平台工具注册与 OpenAPI 接入说明
```

约定：密钥不入库不入包；环境变量外置；数据库脚本版本化。

# 恒脑平台编排操作要点（官方使用说明节选整理）

> 状态：基线 v1.0（2026-10-11）
> 来源：恒脑平台官方使用说明文档（用户提供节选）；原始文档未获 PDF，如需完整版向平台方索取
> 用途：支撑 T27（恒脑侧智能体编排）设计与平台操作；本文件是"怎么在平台上做"的操作级要点

## 1. API 工具配置

API 工具 = 能力集合，一个 API 工具可添加多个安全能力项；能力项注册后可在编排智能体时被选中调用。

**创建流程**：创建 API 工具 → 添加能力项 → 配置基础信息 → 配置输入参数 → **调试**（自动构造请求并发起测试，调试成功才能被智能体选中）→ 配置输出参数（"立即解析"按响应自动填充）。

关键配置：

| 配置项 | 要点 |
| --- | --- |
| 能力名称/描述 | 大模型据此选择能力，名称描述要清晰（影响工具选择准确率） |
| 接口地址/请求方法 | GET/POST；确保网络可达 |
| 是否使用恒脑大模型 | 内部配置，默认"关闭" |
| 是否返回文件 | 开=文件规范接收；关=RESTful 规范 |
| 输入参数 | 类型 String/Integer/Number/Float/Boolean/Array/Object/File；位置 query/path/header/body；参数名与说明影响大模型自动构造参数 |
| 输出参数 | "是否流式"可指定流式输出字段 |

## 2. MCP 工具创建

- 支持在**平台提供列表中选择已有 MCP**（自动填充配置，按需配置环境变量）；
- 支持**自定义配置**手动填写；
- 保存并发布后校验能力可用性。

## 3. 知识库

安全知识库 = 历史知识/经验载体；上传文档自动解析+向量化，智能体通过 RAG 召回。

- 类型：**文本库**（直接上传，按分块/分隔符切分，问题匹配答案）；**问答对库**（下载模板填写，按行切分，FAQ 场景）；
- 限制：单库 ≤20 文件、单文件 ≤100M；格式 doc/docx/pdf/json/txt/xls/xlsx/ppt/pptx；
- 分块：大小 256–1024，默认 512；分隔符与分块大小二选一；
- 图片理解：可开启（调用图片提取能力）；
- 索引状态：未开始 → 索引中 → 已就绪 / 失败。

## 4. 工作流节点（编排画布）

| 节点 | 用途与要点 |
| --- | --- |
| 开始节点 | 全局输入参数与模型配置；不可删除；只能连一个入口节点 |
| 模型节点 | 指定大模型调用；**可自主调用 API 工具/知识库/智能体**（智能体应用仅支持插件+知识库；智能体组合仅支持智能体）；支持迭代（Array 长度，默认 10 次，最大 32） |
| 插件节点 | 指定 API 工具能力项调用；仅调试成功的能力可选 |
| 代码节点 | 自定义 Python/JavaScript 代码；变量按示例引用方式传递 |
| 交互节点 | 输出消息 + 双向交互（填空/单选/多选/单文件/多文件）；**对应开放接口的交互回答（question→resume）** |
| 自规划节点 | 大模型自主分解复杂目标并规划执行路径；**必须选最大上下文 ≥128K 的模型**；可配置 MCP 与 Skills（任务规划/工具选择/编排落点） |
| 智能体节点 | 调用同租户已发布智能体或收藏的智能体 |
| 结束节点 | 回答内容与输出参数；返回文件时引用文件变量并设 File/Files 类型 |

## 5. 发布机制（重要）

- 智能体编排调试完成后必须**发布**才可被调用；发布到"智能体探索"并控制发布范围；
- 发布后生成**唯一智能体 ID**；"我的创建"中的未发布智能体**无法被调用**；
- **这解释了开放接口 `agent/search` 实测返回 0 条**——当前没有已发布且对应用户可见的智能体。

## 6. 对本项目编排设计的映射（T27）

| 赛题能力 | 编排节点组合建议 |
| --- | --- |
| 任务规划/工具选择 | 自规划节点（选 ≥128K 模型）+ MCP（Nuclei/Nmap/SSL 等白名单内工具） |
| 知识增强（敏感规则/漏洞知识） | 知识库（文本库）→ 模型节点/知识检索插件 |
| 页面发现 | 子域名发现/证书透明查询 MCP + 代码节点（自研爬虫逻辑） |
| 人工确认（授权/范围） | 交互节点（question → 开放接口 resume） |
| 检测执行 | 插件节点（API 工具能力项）+ 代码节点（编排/限速/聚合） |
| 结果输出 | 结束节点输出参数（results 对象） |

# 网站安全常见漏洞与修复建议（安全巡检知识库内容源）

> 用途：恒脑平台"安全巡检知识库"文本库内容（上传本文件，供巡检智能体生成可解释证据与修复建议）
> 说明：面向授权范围内非破坏巡检场景；与 Nuclei 模板检测项对齐

## 1. 注入类

### SQL 注入
- 特征：URL 参数、表单输入可拼接 SQL；报错信息泄露数据库结构；时间盲注延迟。
- 证据：参数值加 `'` 或 `"` 触发异常；与基线响应对比。
- 修复：参数化查询（PreparedStatement）/ 转义；最小权限数据库账号；WAF 兜底。

### 命令注入
- 特征：输入拼接进系统命令（如 ping、whoami）。
- 修复：禁止拼接 shell；白名单校验；沙箱执行。

## 2. 跨站脚本（XSS）
- 特征：输入回显未转义，`<script>`、事件属性可执行。
- 证据：注入 `<script>alert(1)</script>` 后响应回显原样。
- 修复：输出编码（HTML/JS/URL 上下文）；CSP 头；HttpOnly Cookie。

## 3. 跨站请求伪造（CSRF）
- 特征：表单无 token；请求无来源校验。
- 修复：CSRF Token；SameSite Cookie；校验 Origin/Referer。

## 4. 文件上传
- 特征：可上传可执行文件（.php/.jsp/.asp）；上传目录可访问。
- 修复：扩展名白名单 + 内容校验；上传目录禁止执行；随机文件名。

## 5. 弱口令与认证缺陷
- 特征：默认口令（admin/admin、root/root）；无锁定策略；明文传输。
- 修复：强制强口令；登录失败锁定；HTTPS；多因素认证。

## 6. 信息泄露
- 特征：目录列表开启；备份文件（.bak/.sql/.git）；报错堆栈；调试接口暴露；敏感字段明文。
- 修复：关闭目录列表；删除备份/调试文件；统一报错页；敏感数据脱敏与加密。

## 7. 传输安全（SSL/TLS 弱配置）
- 特征：证书过期/自签名；TLS 1.0/1.1；弱加密套件；HSTS 缺失。
- 证据：SSL/TLS 检测返回协议与证书信息。
- 修复：有效证书；TLS 1.2+；强套件；启用 HSTS。

## 8. 配置缺陷
- 特征：默认页面未移除；错误配置的 CORS；未授权接口（/admin、/api/swagger 等）。
- 修复：移除默认页；CORS 白名单；接口鉴权。

## 9. 挂马与页面篡改
- 特征：页面被插入恶意 iframe/JS；外链指向未知域名；文件哈希与基线不一致。
- 修复：文件完整性基线；篡改告警；内容安全策略；定期比对。

## 10. 敏感信息暴露（泄露）
- 特征：页面/文件含手机号、身份证、银行卡、密钥、内网地址、数据库连接串等。
- 证据：正则/关键词命中 + 上下文（敏感信息需脱敏后展示）。
- 修复：下线暴露文件；脱敏存储；访问控制；扫描规则持续更新。

## 附录：Nuclei 常用模板类别（非破坏模板化检测）
- `http/`：通用 Web 检测（暴露面板、默认口令、CVE 指纹）
- `ssl/`：TLS 配置检测
- `exposures/`：信息泄露/备份文件/配置文件暴露
- `misconfiguration/`：错误配置（CORS、目录列表等）
- `cves/`：已公开漏洞指纹（按授权范围选择模板）

> 修复建议仅为通用指引，具体处置以现场确认与厂商建议为准。

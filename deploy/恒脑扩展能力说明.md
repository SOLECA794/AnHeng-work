## 2. Chatbot 扩展插件（T05，iframe 集成）

恒脑 Chatbot 可通过独立 iframe 嵌入第三方系统页面，直接获得安全垂域大模型对话交互。

**流程**：服务端取 token → Web 端 iframe 嵌入 → 服务端注销/校验 token。

**接口**：

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/open/api/assistants/token` | POST | 获取 iframe 访问凭证 token（Body: `userId` 集成方用户唯一标识） |
| `/open/api/assistants/token/delToken` | POST | 注销 token（Body: `token`），用于主动登出 |
| `/open/api/assistants/token/checkWithRefresh` | POST | 校验 token 并按需刷新有效期（Body: `token`、`refresh` 默认 true） |

**iframe 嵌入**：

```html
<iframe src="http://{host}/chatbot?appType=assistants&token=xxx" width="100%" height="100%"></iframe>
```

**本项目决策建议**：
- 作为**可选集成方案**：管理端"智能体对话"页可二选一——(a) 恒脑 Chatbot iframe 嵌入（零开发、体验完整）；(b) 自研对话 UI 走 `agent/execute` 流式（可控、可审计、可替换平台）。
- 若选 (b) 为主，iframe 可作为演示/兜底方案；两种方案都保留，评审后定。
- `userId` 应传本项目用户 ID（如 sys_user.id 的脱敏值），便于恒脑侧会话归属。

## 3. 知识检索与创作（T06，知识库接入）

**接口族**（`/open/api/v2/document/*`）：

| 接口 | 方法 | 说明 | 本项目用途 |
| --- | --- | --- | --- |
| `/document/upload` | POST | 文件预处理上传（异步任务，返回 taskId） | 上传敏感信息规则文档、安全知识库文档 |
| `/document/task/status` | GET | 上传处理状态查询 | 轮询处理结果 |
| `/document/delete` | POST | 文件数据删除 | 规则库版本替换时清理 |
| `/document/attribute_update` | POST | 文件属性更新 | 规则文档元信息维护 |
| `/document/internal_download` | GET | 内置文件下载 | 获取处理产物 |
| `/document/metadata_query` | POST | 文件元数据查询 | 单文档信息 |
| `/document/metadata_page_query` | POST | 文件列表分页查询 | 知识库管理页 |
| `/document/retrieve` | POST | 检索原文（RAG 检索） | **敏感信息规则命中检索、安全知识检索** |
| `/document/chat` | POST | 检索问答（带引用） | 智能体问答增强（引用溯源） |
| `/document/creation` | POST | 文档创作 | 报告/知识生成（可选） |
| `/document/translate` | POST | 文档翻译 | 非本项目核心 |
| `/document/stop` | GET | 会话停止 | 长任务中断 |

**本项目落地建议**：
- 知识库承载两类内容：**敏感信息定义库**（关键词/正则/样例文档，供敏感信息检测器做语义补充）与**安全巡检知识库**（漏洞说明、修复建议，供智能体生成可解释证据与建议）。
- 集成位置：能力服务新增 `knowledge/` 适配模块，封装 upload→status 轮询→retrieve/chat，接口收敛为项目内部统一服务，平台可替换。

## 4. 大模型问答（T02 / T27，OpenAI 兼容）

**关键结论：恒脑大模型接口兼容 OpenAI Chat Completions 协议**，可用标准 OpenAI SDK 直接调用。

- 接口：`POST /api/openai/v1/chat/completions`
- 鉴权：`Authorization: Bearer <LLMKey>`（LLMKey 与用户绑定；与 appKey/sign 是两套鉴权）
- 能力：流式/非流式、tools/tool_choice（函数调用）、reasoning_content、Vision（图片仅支持 Base64/Data URI）、structured_outputs、model 如 HengNao-v4

**对架构的意义**（增强"脱离平台绑定"）：
- 若智能体编排需要底层模型直连（例如自研编排而非恒脑能力中台），可基于 OpenAI 兼容协议 + tools 实现工具调用循环；
- AgentProvider 抽象不变：`execute 流式` 对应恒脑智能体接口，底层模型接口作为备选实现路径；
- 本项目默认走恒脑智能体编排（能力中台），大模型接口作为**降级与对比基线**保留。

## 5. 租户用量统计（T07 / 审计）

- 接口：`GET /open/api/v2/tenant/usage/statistics`（无参数）
- 返回：`callCount`（累计智能体成功调用次数）、`tokenUsage`（累计 Token 用量 prompt+completion）
- 注意：租户由鉴权自动确定，不支持传 tenantId；受当日调用次数限制控制
- 本项目用途：管理端审计页展示"恒脑用量"卡片；接近限额时预警（配合 -304 状态码处理）

## 6. 系统信息同步（T07 / 限流实测）

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/open/api/system/info` | GET | 系统时间、流量（used/free/expire）、各接口并发配额（usedConcurrent/freeConcurrent/totalConcurrent）、状态（畅通/拥挤/拥堵） |
| `/open/api/system/upgrade` | GET | 系统升级信息 |
| `/open/api/system/metric/query_range` | GET | 观测数据查询（指标时间序列） |
| `/open/api/system/queryToken` | GET | token 结算信息查询 |

**Phase 0 实测重点**：`/system/info` 返回各接口并发配额，可直接量化本项目可用的并发上限，用于限速参数定标（工具编排限速、巡检调度并发度）。

## 7. 状态码速查（扩展补充）

| Code | 含义 |
| --- | --- |
| 0 | 成功 |
| -304 | 今日接口调用次数已达限制 |
| -401 | 参数异常 |
| -402 | 认证失败（多为本地服务器时间偏差） |
| -403 | 权限不足（智能体服务接口） |
| -404 | 租户不存在 |
| -405 | 不支持的请求方法 |
| -500 | 服务内部错误 |
| -502 | 无可用服务 |
| -503 | 远程服务异常 |
| -504 | 远程过程调用异常 |

flag：0 成功；1 请求处理失败可跳过；2 服务异常需停止等待后重试。

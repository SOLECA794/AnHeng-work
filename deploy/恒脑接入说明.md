# 恒脑接入说明（基于《智能体服务-开放服务接口》）

> 状态：基线 v1.0
> 关联文档：`deploy/恒脑扩展能力说明.md`（插件/知识库/大模型/用量/系统信息接口）；原始文档：`deploy/恒脑平台文档/`
> 来源：恒脑《智能体服务-开放服务接口》接入文档（用户提供，部分章节）；正式接入以平台最新接口文档为准。
> 关联设计：SDD-01 §5.2（智能体编排）、§5.8（非破坏与合规）

## 1. 接入总览

恒脑通过开放接口（OpenAPI）提供**智能体全生命周期管理及调用**。本项目对接方式：

- **智能体侧**：在恒脑平台（能力中台 → 安全智能体管理）可视化编排智能体（任务规划、插件工具调用、知识库检索），可参考 AgentManifest 清单；
- **应用侧**：本项目能力服务通过恒脑 OpenAPI 调用智能体（对话、异步巡检任务、交互回答）；
- **能力侧**：本项目自研检测能力以**插件工具/知识库**形式接入恒脑（恒脑支持接入插件工具与知识库），或由智能体调用能力服务 API 完成业务闭环。

## 2. 鉴权认证

1. 从平台获取 `appKey` 与 `appSecret`（appKey 为应用标识，appSecret 为应用密钥）；
2. 生成签名 sign：基于 HmacSHA256，以当前时间戳为盐值，对 appKey 与 appSecret 哈希：

```
sign = timestamp + base64(HmacSHA256( secret=appSecret, data="{timestamp}\n{secret}\n{key}" ))
```

Python 参考：

```python
import hmac, hashlib, base64, time

def get_sign(key, secret):
    timestamp = int(time.time() * 1000)
    data = f"{timestamp}\n{secret}\n{key}"
    digest = hmac.new(secret.encode(), data.encode(), hashlib.sha256).digest()
    return f"{timestamp}{base64.b64encode(digest).decode()}"

sign = get_sign(app_key, app_secret)   # header: appKey, sign
```

3. 访问凭证：header 携带 `appKey` 与 `sign`；
4. 安全约束：
   - **绝不携带 appSecret 调用接口**；
   - appKey/appSecret/sign 不得硬编码、不得共享（本项目由能力服务保管并生成签名，前端不可见）；
   - 签名有效期 60 分钟，需保证服务器时间正确（签名失败常见原因为本机时间偏差）。

## 4. 关键机制说明

### 4.1 同步执行与流式（接口 1）

- 请求：`{ sid(UUID), id(智能体ID), input/inputs, stream, order, debugSwitch }`；
- 非流式：返回 `AgentResult{session, results, token_usage}`；
- 流式（SSE）：`data:` 逐条推送 `AgentResult`，`mode=preview`，`type=inline/custom`，`from` 标识消息来源：
  - `basic_llm / react_think / react_action / react_observe / react_answer`：思考与执行过程；
  - `retrieval_doc_* / retrieval_sql_*`：知识库/结构化检索过程；
  - `restful_answer / execute_result`：最终结果（`results` 含执行结果参数）。
- `message_id` 相同表示分片拼接，前端按 message_id 聚合展示；
- `ext` 扩展参数：`child_preview`（子智能体预览）、`reason`（推理过程独立返回，后端处理建议 `reason=1`）。

### 4.2 异步任务（接口 7/8/9/10）

长任务（巡检）使用异步通道：

```
task/submit → taskId
task/status 轮询：1 运行 → 2 完成（3 取消 / 4 失败）
task/messages 取结果（full=true 全量 / false 增量）
```

本项目策略：**巡检走异步任务通道**（周期长、不阻塞对话）；对话交互走 execute 流式。

### 4.3 交互回答（接口 11）

- execute 流式输出中可能出现 `mode="question"` 消息（含问题、选项、message_id、qid）；
- 前端渲染问题 → 用户回答 → 调用 execute/resume（`messageId` + `inputs`）→ execute 继续输出；
- 问答结果按 `_question/_options/_answer` 存储；
- 本项目场景：巡检授权确认、检测范围确认、敏感规则示例确认等人工确认环节。

### 4.4 文件（接口 4/5）

- 上传返回 `file:xxx<uuid>` 文件 id，可作为 inputs 中文件类型参数传入；
- 本项目场景：敏感信息样例文件、报告附件素材。

## 5. 状态码与反馈标识

- `flag` 服务调用反馈：0 成功；1 请求处理失败（可跳过）；2 服务异常（停止调用，稍后重试）；
- 业务状态码（节选）：

| code | 含义 | 处理 |
| --- | --- | --- |
| 0 | 成功 | — |
| -402 | 认证失败（签名/时间） | 检查服务器时间与签名生成 |
| -403 | 缺少权限 | 检查 appKey 授权范围 |
| -304 | 今日调用次数达限 | 限流退避 |
| -301/-300 | 并发/连接超限 | 排队重试 |
| -200 | AI 引擎调用出错 | 适配层报 50001，降级 |
| -500/-502/-503/-504 | 服务端异常 | 适配层报 50001，重试 |

能力服务适配层需将恒脑状态码映射为本项目错误码（SDD-03 §3）。

## 6. AgentManifest 概要（智能体侧配置）

智能体清单结构（恒脑侧定义）：id、name、description、system/user_prompt_template、input/output_parameters、model（模型+温度）、entry、nodes（节点，类型 `llm_basic`）、edges（边，条件语法 expr-lang）、result_parsers（`parser_regex`）。

本项目使用要点：
- 在能力中台可视化编排巡检智能体：入口节点 → 插件工具节点（调用能力服务检测工具）→ 结果汇总；
- 输入参数定义（input_parameters）：`target_url / scope / check_types / sensitive_rules` 等，与能力服务 API 对齐；
- 输出参数定义：`findings / summary / report_id` 等，供 execute 的 `results` 返回。

## 7. 本项目接入设计约束

| 约束 | 落地 |
| --- | --- |
| 凭据安全 | appKey/appSecret 仅存能力服务（环境变量），前端不可见；签名由服务端生成 |
| 可替换性 | 恒脑调用收敛在 `agent/` 编排适配层，定义统一 `AgentProvider` 接口（execute/stop/asyncSubmit/asyncStatus/asyncMessages/resume/upload/download），恒脑为当前实现，可替换 |
| 超时与重试 | execute 设置超时；异步任务轮询有上限；flag=2 停止重试等待 |
| 权限映射 | 本项目用户角色 → 恒脑智能体授权范围，越权禁止 |
| 审计 | 每次恒脑调用写 agent_log（接口、参数摘要、状态、耗时、token） |

## 8. Phase 0 实测清单（接入前必须验证）

1. appKey/appSecret 申请与签名生成（服务器时间校验）；
2. execute 流式连通性（SSE 消息结构、message_id 聚合）；
3. 异步任务全链路（submit → status → messages）；
4. 交互回答流程（question 消息 → resume）；
5. 插件工具接入方式（本项目能力服务如何注册为工具/插件）；
6. 知识库接入方式（风险知识/修复建议库是否需要挂恒脑知识库）；
7. 状态码与限流实测（并发、日限额）。
